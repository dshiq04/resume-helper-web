# 履途 ResumeTrail · 浏览器扩展

Manifest V3 扩展，用于替代原桌面端的独立快速录入窗口。

## 安装

1. 启动网页端（默认 `http://127.0.0.1:18080`）。
2. 打开 `chrome://extensions` 或 `edge://extensions`。
3. 开启「开发者模式」。
4. 点击「加载已解压的扩展程序」选择本目录，或把根目录的 `extension.crx` 拖入扩展管理页。

## 配置

打开扩展的「设置」页：

- 服务器与端口：默认 `http://127.0.0.1` + `18080`；
- 授权码：在网页端「账户设置 → 授权码」生成，只读 / 读写均可连接，录入需要读写权限；
- 保存时会调用 `/api/tokens/validate` 校验授权码是否存在、是否过期、账号是否正常；
- 扩展只把服务器地址与授权码保存在 `chrome.storage.local`，不再使用账号密码登录。

## 使用

- 点击工具栏图标，或按 `Alt+Shift+J` 打开快速录入；
- 链接会自动填入当前标签页地址，公司名称会尝试从页面标题猜测；
- 在招聘页右键选择「加入履途 ResumeTrail」，会打开一个独立的小窗口并预填当前链接；
- 公司名称与投递链接必填，其余字段可选；
- 提交成功后窗口保持打开，方便连续录入。

录入记录的「年度」以服务器时间为准：扩展会调用 `/api/health` 获取服务器时间，跨年度补录时不会受本机时钟影响。

## 权限与报错

- 授权码不存在 / 已删除：`401`，禁止录入；
- 授权码已停用或账号异常：`403`，禁止录入；
- 授权码已过期：`410`，禁止录入；
- 只读授权码可以连接，但保存时会提示需要读写权限；
- 无法连接服务器时，弹窗与设置页会明确提示「暂时无法连接到服务器」，不会显示空白内容。
