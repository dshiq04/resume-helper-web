# 履途 ResumeTrail · 浏览器扩展

Manifest V3 扩展，用于替代原桌面端的独立快速录入窗口。

## 安装

1. 启动网页端（默认 `http://127.0.0.1:18080`）。
2. 打开 `chrome://extensions` 或 `edge://extensions`。
3. 开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本目录 `extension/`。

## 配置

打开扩展的「设置」页：

- 服务端地址：默认 `http://127.0.0.1:18080`；
- 使用网页端的账号登录。扩展只保存 JWT token 到 `chrome.storage.local`；
- 如果服务端开启验证码（`captcha.enabled=true` 且 Redis 已启用），设置页也会显示验证码输入。

## 使用

- 点击工具栏图标，或按 `Alt+Shift+J` 打开快速录入；
- 链接会自动填入当前标签页地址，公司名称会尝试从页面标题猜测；
- 在招聘页右键选择「加入履途 ResumeTrail」，会打开一个独立的小窗口并预填当前链接；
- 公司名称与投递链接必填，其余字段可选；
- 提交成功后窗口保持打开，方便连续录入。

扩展支持「年度」字段，与网页端的多年度投递保持一致。
